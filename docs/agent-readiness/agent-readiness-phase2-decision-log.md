# Phase 2 Decision Log

This log preserves the accepted, amended, and open decisions that define the toolkit's
Phase 2 architecture.

## Document status

This log records product and architecture decisions for
`docs-agent-readiness-toolkit` made during Phase 2 Generalisation.
`ACCEPTED` decisions constrain the specification. The later "Consequences for Phase 3"
section records the user-authorized prototype exception. Open implementation choices
retain an explicit uncertainty label.

The decisions were informed by a reviewed Rootstock case-study archive and competitive
research. Those source materials are retained outside the public repository. This
public log records the generalized decisions and their uncertainty labels without
distributing the underlying research corpus.

## Consequences for Phase 3

The implemented Phase 3 slice contains MVP-0, MVP-1, and Stage 2 recorded AFDocs
import. The practitioner validation protocol is ready and remains `NOT_RUN`. The six
canaries are the acceptance set. Live acquisition remains blocked by its security gate.

### Phase 3 pre-validation amendments

These amendments clarify repository and prototype details without replacing the
underlying Phase 2 decisions.

- **ADR-001:** The accepted row records the repository identity chosen during Phase 2.
  As of 2026-09-11, the canonical GitHub repository is
  `owans/docs-agent-readiness-toolkit`. The local directory, package name, and
  executable-name decision are unchanged.
- **ADR-011:** Compatibility reasons now identify parser, canonicalizer, and identity
  algorithm changes independently. This clarification preserves the chosen exact,
  versioned fingerprint strategy.
- **ADR-012:** The five canonical states remain unchanged. A status transition such as
  `PASS` to `FAIL` is serialized as `CHANGED` with `previous_status` and
  `current_status`, not as an additional state.
- **ADR-015 and ADR-023:** A baseline external check absent from current imported
  evidence is unavailable comparison evidence. Its item-level state is `INCOMPATIBLE`
  with `EXTERNAL_CHECK_UNAVAILABLE`, not `RESOLVED`.
- **ADR-033:** Identity status describes declared relationships between targets.
  Authenticity describes evidence's claimed origin. DART-OPS-003 reports evidence
  properties without deriving lineage; DART-OPS-001 and DART-OPS-002 retain
  responsibility for relationship findings.

The user explicitly authorized the tiny Phase 3 prototype. This does not authorize
package publication, production deployment, live collection, or broad rules.
